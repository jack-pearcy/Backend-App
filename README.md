Developed a modern Java Spring Boot back-end for a travel agency’s Angular front-end vacation booking system. Migrated critical legacy functionalities from a 1990s-era back-end to a secure, maintainable Spring Framework application. Integrated with an existing MySQL database, implemented RESTful endpoints, handled purchase workflows, and ensured compatibility with the provided Angular front-end. Focused on clean architecture, efficient database access, and modern software development practices.
